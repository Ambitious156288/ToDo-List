# Getting Started with This Project

This is a **Next.js** project with MUI [`create-next-app`](https://nextjs.org/docs/pages/api-reference/create-next-app).

## Install packages

```bash
npm i / yarn / pnpm install
```

## Start local server

```bash
npm run dev / yarn dev / pnpm dev
```
